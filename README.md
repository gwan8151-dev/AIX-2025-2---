# 2. YOLO 모델에 대해서

## 2.1 객체 탐지(Object Detection)란?

먼저 YOLO를 이해하기 위해 **객체 탐지**가 무엇인지 알아야 한다.

### 이미지 분류 vs 객체 탐지

**이미지 분류(Image Classification)**

- "이 사진은 무엇인가?" → "개 사진입니다"
- 전체 이미지를 보고 하나의 정답만 제시한다.

**객체 탐지(Object Detection)**

- "이 사진에 무엇이 어디에 있나?" → "개가 왼쪽에, 고양이가 오른쪽에 있습니다"
- 여러 물체의 **위치**와 **종류**를 동시에 찾아낸다.

### 객체 탐지의 두 가지 과제

1. **Classification (분류)**: 이게 무엇인지 판단한다.
2. **Localization (위치 찾기)**: 어디에 있는지 박스로 표시한다.

YOLO는 이 두 가지를 **동시에** 수행하는 모델이다.

## 2.2 YOLO란?

**YOLO(You Only Look Once)**는 2016년에 처음 발표된 실시간 객체 탐지 알고리즘이다.

### 왜 YOLO라는 이름일까?

기존의 객체 탐지 방법들은 이미지를 여러 번 반복해서 분석했다. 예를 들어:

- 1단계: 물체가 있을 만한 영역 찾기
- 2단계: 각 영역을 다시 분석해서 물체 분류하기
- 3단계: 결과 정제하기

하지만 YOLO는 이름 그대로 **"단 한 번만 보고(You Only Look Once)"** 모든 작업을 끝낸다.

### 쉬운 비유로 이해하기

**기존 방식 (R-CNN 계열)**

- 선생님이 교실을 둘러보며 한 명씩 "너는 학생이니?" 확인한다.
- 느리지만 꼼꼼하다.
- 한 장의 사진을 분석하는데 수십 초 소요한다.

**YOLO 방식**

- 선생님이 교실을 한 번 쭉 보고 "1번 자리 학생, 3번 자리 선생님, 5번 자리 학생" 한 번에 파악한다.
- 빠르지만 가끔 놓칠 수 있다.
- 한 장의 사진을 분석하는데 0.03초 소요한다. (초당 30장 이상)

### YOLO의 혁신적인 점

**속도**: 실시간(30 FPS 이상)으로 동작 가능하다.

- 자율주행차, CCTV 모니터링 등에 활용한다.
- 비디오에서도 즉시 물체 추적 가능하다.

**정확도**: 빠르면서도 꽤 정확하다.

- 초기 버전은 정확도가 낮았지만 계속 개선하고있다.
- 현재(v8)는 속도와 정확도 모두 우수하다.

**간단함**: 하나의 신경망으로 모든 처리한다.

- 복잡한 파이프라인이 없다.
- 학습과 사용이 간단하다.

## 2.3 YOLO의 작동 원리

### Step 1: 이미지를 격자로 나누기

입력 이미지를 **S × S 격자(Grid)**로 나눈다. (예: 13×13, 19×19)

```
┌─┬─┬─┬─┬─┬─┬─┐
├─┼─┼─┼─┼─┼─┼─┤
├─┼─┼─┼─┼─┼─┼─┤  
├─┼─┼─┼─┼─┼─┼─┤  ← 7×7 격자 예시
├─┼─┼─┼─┼─┼─┼─┤
├─┼─┼─┼─┼─┼─┼─┤
├─┼─┼─┼─┼─┼─┼─┤
└─┴─┴─┴─┴─┴─┴─┘
```

### Step 2: 각 격자 셀의 역할

각 격자 셀은 다음을 예측한다:

**1. 바운딩 박스(Bounding Box)**

- 물체를 감싸는 사각형
- 각 셀은 여러 개의 박스를 예측 (보통 2-3개)
- 박스 정보: (x, y, w, h)
    - x, y: 박스의 중심 좌표
    - w, h: 박스의 너비와 높이

**2. 신뢰도(Confidence Score)**

- "이 박스에 물체가 있을 확률" × "박스가 얼마나 정확한가"
- 0~1 사이의 값
- 예: 0.95 → 95% 확신

**3. 클래스 확률(Class Probabilities)**

- 이 물체가 각 클래스일 확률이다
- 예: 강아지 80%, 고양이 15%, 새 5%

### Step 3: 예측 결과 생성

각 격자의 예측을 합치면:

- 수천 개의 바운딩 박스가 생성된다.
- 대부분은 신뢰도가 낮다.

### Step 4: 필터링 (NMS - Non-Maximum Suppression)

**문제**: 같은 물체에 여러 박스가 겹쳐 그려진다

**해결**: 비최댓값 억제(NMS) 기법 사용

1. 신뢰도가 낮은 박스 제거한다. (임계값 이하)
2. 겹치는 박스 중 가장 좋은 것만 선택한다.
3. 최종적으로 깔끔한 결과만 남긴다.

### 핵심 아이디어

**단일 신경망 통과**

- 입력 → CNN → 출력 (한 번에)
- 복잡한 여러 단계가 없다.

**전역적 추론(Global Reasoning)**

- 전체 이미지를 보고 판단한다.
- 물체의 맥락(context) 이해한다.
- 예: 배경을 보고 물체 유형 추론이다.

**End-to-End 학습**

- 입력부터 출력까지 하나의 네트워크로 학습한다.
- 각 부분을 따로 학습할 필요 없다.

## 2.4 YOLO의 발전 과정

YOLO는 2016년 첫 등장 이후 지속적으로 발전했다.

**YOLOv1 (2016)**

- 최초의 실시간 객체 탐지 모델
- 빠르지만(45 FPS) 정확도는 보통(63.4% mAP)
- 한계: 작은 물체 탐지 어려움이 있다.

**YOLOv2-v3 (2017-2018)**

- Anchor Box 도입, 다중 스케일 예측
- 정확도 크게 향상(78.6% mAP)
- 작은 물체 탐지 부분을 개선했다.

**YOLOv4-v5 (2020)**

- 최신 학습 기법 적용했다.
- PyTorch 구현으로 사용 편의성 대폭 향상했다.
- 5가지 크기 모델 제공(n, s, m, l, x)

**YOLOv8 (2023, 최신)**

- Ultralytics에서 개발
- Anchor-free 방식, 향상된 손실 함수
- 가장 쉽고 강력한 버전

| **모델** | **특징** | **mAP** |
| --- | --- | --- |
| YOLOv8n | 가장 가볍고 빠름 | 37.3 |
| YOLOv8s | 속도와 정확도 균형 | 44.9 |
| YOLOv8m | 중간 크기 | 50.2 |
| YOLOv8l/x | 높은 정확도 | 52.9-53.9 |

## 2.5 YOLO의 장단점

### 장점

**1. 압도적인 속도**

- **실시간 처리**: 초당 30-100 프레임 이상이다.
- **즉각적인 피드백**: 비디오 스트림에서도 사용 가능하다.
- **응용 분야**: 자율주행, 드론, 실시간 모니터링

**2. 한 번에 전체 이미지 분석**

- **전역적 맥락 이해**: 배경 정보도 활용가능하다.
- **False Positive 감소**: 배경을 물체로 오인하는 경우가 적다.
- **관계 이해**: 물체 간의 관계도 파악가능하다.

**3. 일반화 성능 우수**

- **새로운 이미지에 강함**: 다양한 환경에서 작동한다.
- **도메인 전이**: 한 분야에서 학습한 모델을 다른 분야에 적용 가능하다.

**4. 단순한 파이프라인**

- **하나의 네트워크**: 복잡한 여러 단계 불필요하다.
- **학습 간단**: End-to-End 학습
- **배포 쉬움**: 모델 하나만 있으면 된다.

**5. 다양한 크기 물체 탐지**

- **멀티스케일**: 작은 물체부터 큰 물체까지 가능하다.
- **밀집된 물체**: 여러 물체가 모여있어도 탐지 가능하다.

**6. 활발한 커뮤니티와 생태계**

- **풍부한 자료**: 튜토리얼, 예제 코드가 많다.
- **지속적인 발전**: 새로운 버전이 계속 출시된다.
- **다양한 구현**: PyTorch, TensorFlow 등

### 단점

**1. 작은 물체 탐지의 어려움**

- **이유**: 격자 크기의 제약이 있다.
- **영향**: 멀리 있는 물체나 작은 물체 놓칠 수 있다.
- **예시**: 드론으로 찍은 고도에서 사람 탐지, 작은 나사나 부품

**2. 밀집된 작은 물체**

- **한계**: 한 격자에 여러 물체가 있으면 일부만 탐지된다.
- **예시**: 새 떼, 작은 물체가 여러 개 모여있는 경우

**3. 정확한 위치 지정의 제약**

- **이유**: 격자 기반 예측
- **영향**: 바운딩 박스가 완벽히 정확하지 않을 수 있다.
- **대안**: Instance Segmentation 모델 (Mask R-CNN 등)

**4. 학습 데이터 의존성**

- **필요**: 각 클래스별로 충분한 학습 데이터 필요하다.
- **문제**: 드문 케이스는 학습 어렵다.
- **해결**: 데이터 증강, 전이 학습 활용

**5. 하드웨어 요구사항**

- **GPU 필요**: 빠른 추론을 위해 GPU 권장
- **메모리**: 큰 모델은 많은 메모리 필요하다.
- **대안**: 경량 버전 사용 (YOLOv8n)

**6. 겹치는 물체 구분 어려움**

- **문제**: 물체가 완전히 겹쳐있으면 하나로 인식한다.
- **예시**: 포개진 접시, 겹쳐진 사람들

### 문제 원인일 가능성이 있는 요인들

**1) 라벨 불일치 문제**

YOLO는 **클래스 번호가 0~N-1 순서로 정확히 매칭**돼 있어야 한다. 단 classes.txt 순서와 각 라벨의 .txt 안의 클래스 번호가 매칭 되지 않은 데이터가 일부 있는 것으로 확인되었다.

이는 수정 후 다시 학습을 진행해 볼 예정이다.

---

**2) 적은 학습 데이터의 수**

현재 클래스 당 40장 정도의 데이터로 학습을 진행하였다.

이러한 경우 loss는 줄지만 model이 아무것도 확신하지 못하는 상태가 되어 confidence가 0.25를 넘기지 못해 박스가 아예 출력되지 않았을 가능성이 있다.

---

**3) threshold(신뢰도 기준)이 너무 높음 (2번과 비슷한 맥락)**

YOLO predict 기본 threshold는 conf=0.25이다.

학습 데이터가 적으면 모든 예측이 conf < 0.25로 떨어지므로 박스가 생성되지 않았을 가능성이다.

이를 검증하려면 

```
yolo predict model=best.pt source=images/ conf=0.05
```

처럼 threshold를 낮춰보면 된다는 것을 조사를 통해 알게 되었다. 추후 여러 원인 가능성에 대한 분석 후 내용 추가 예정이다.

---

**4) 라벨 좌표 형식 오탈자/스케일 문제**

YOLO 라벨에서 좌표는 반드시 {class x_center y_center width height } (모두 0~1 범위) 와 같은 형태여야 한다.

만약 width/height이 1을 넘기거나 음수이거나, x_center,y_center이 0~1 벗어나는 데이터가 있을 경우 학습과 예측에 지장을 줄 수 있다. 이는 전처리 코드를 추가하는 것으로 해결할 수 있다.

### (4) 오류 해결 과정
